# 小工具

一个多功能小型网页工具，集成了投票功能和石头剪刀布游戏，帮助你和小伙伴出行聚会时快速决定去哪里、玩什么，解决“选择困难症”！

## 演示网站

[点击此处访问项目演示网站](https://xunuoxie.github.io/webapp_vote/)

## 功能简介

### 普通投票模式
- 支持自定义投票选项
- 可选择单选/多选
- 支持为用户随机分配投票

### 石头剪刀布模式
- 支持2人以上的石头剪刀布游戏
- 支持多轮比较（1-10轮）
- 自动计算胜负和总得分
- 显示详细的游戏结果

### 通用功能
- 页面简洁，操作方便
- 支持移动端/桌面浏览器
- 支持主题切换

## 使用方法

1. 克隆仓库到本地  
   ```bash
   git clone https://github.com/XUNUO-66/webapp_vote.git
   ```

2. 进入项目目录，打开 `index.html` 即可在本地浏览器访问，无需额外环境依赖。

3. 或者直接部署到自己的服务器/静态空间即可使用。

### 操作流程
1. 打开应用，进入开始界面
2. 选择功能模式：普通投票或石头剪刀布
3. 根据选择的模式进行相应的设置
4. 开始投票或游戏
5. 查看结果
